# Hardik Jaiswal — Portfolio Website

## Project Overview
A premium, immersive personal portfolio website for Hardik Jaiswal, a Software Engineering student specializing in Distributed Systems, AI Orchestration, and High-Concurrency Backend Architecture. The site is directly inspired by [alche.studio](https://alche.studio) — a Three.js-powered, dark, grid-aesthetic, WebGL-driven creative studio site — adapted as a personal developer portfolio with identical visual language, interactions, and structure, but populated with Hardik's personal information.

## Inspiration Reference
**Primary inspiration:** https://alche.studio  
**Style:** Dark cyberpunk-grid, Three.js 3D crystal/prism centerpiece, iridescent materials, monospace UI overlays, immersive scroll-driven sections, floating panel works/projects display.

## Core Philosophy
- Every detail must match the alche.studio quality bar
- No generic, template-style, or "AI slop" aesthetics
- Three.js is mandatory for the 3D crystal H and project panels
- The site should feel like it belongs on Awwwards
- Mobile responsiveness is secondary — desktop-first, but don't break on mobile
